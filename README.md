# 🧾 MKA ERP System

MKA ERP is a business management system designed to streamline daily company operations through role-based workflows and centralized management tools.

### ✨ Implemented Features

* 🔐 Role-based authentication system (Employee, Accountant, Owner, Admin)
* 📱 Dynamic navigation based on user roles
* 📦 Product and inventory management
* 📄 Invoice and quotation management
* ✅ Invoice approval and rejection workflow
* 💸 Expenditure tracking with approval system
* 🚚 Delivery management support
* 👥 Customer and lead management
* 🧾 Audit logging system for company activity tracking
* 📊 Admin audit log dashboard with filters, search, popup details, and CSV export
* 🆕 First-time user onboarding flow customized for each role
* 🌙 Theme toggle support
* 📂 Proof/document URL support for expenditure records
* 🔎 Filtering for expenditures by employee, vehicle, and petty cash usage

### 🛠 Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js + Express
* Database: PostgreSQL (Neon)

MKA ERP is currently focused on creating a practical, scalable internal management platform with real operational workflows and approval systems.
